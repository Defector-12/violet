## 2. 待办

### 当前开发约束

1. AX 失败后使用提问结束时绑定到 `turnId`、最长保留 30 秒的鼠标锚点，不使用视觉
   请求到达时的坐标。
2. 图片 Context 缺少鼠标点，或模型目标框未包含该点时，必须明确回答读不到。
3. OCR 只用于本机秘密阻断和敏感遮挡，不参与目标选择或限制视觉模型置信度。
4. 不得通过降低 `0.7` 置信度、取消目标框或复用旧 Context 让测试表面通过。
5. 先保留失败输入、由 agent 回放修复；只有最终验收或无法代理的系统授权才打断用户。
   确定性测试通过不能代替真实模型统计评估。

### 剩余真实验收

- 鼠标指向、Source Control `33` 徽标、右下角绿色发送按钮。
- 图片预览、PDF、IDE 各 10 次，视觉矩阵剩余 30/50。
- `Look` 关闭与普通非视觉问题各 20 次的无采集门禁。
- 保密应用、绝对秘密、受控敏感遮挡真实矩阵。
- 关闭、替换、超时、锁屏、睡眠、撤权和退出共 50 次生命周期矩阵。
- 新唤醒候选的 20 次短门禁；通过后才扩大到正负样本和 8 小时环境测试。

## 3. 重要提醒

### 感知与隐私

- `Look` 默认关闭；普通问题不截图，视觉问题只在当前轮按需采集。
- 证据优先级：显式 Region > 应用结构化数据 > AX > OCR/视觉 > 推断。
- OCR 只用于设备端秘密阻断和敏感遮挡，不作为截图目标真相。
- 截图只临时驻留，不进入事件账本或长期记忆；旧轮结果必须取消和丢弃。
- 低置信度、无目标框、位置或颜色冲突时必须明确失败。
- 不持续采帧，不新增产品默认图片缓存，不静默读取剪贴板，不增加 Trae 专用适配器。
  本次显式诊断样本的范围和留存见验收文档，不与普通遥测混存。

### 已确认的跨端坑

- Swift UUID 为大写，Core 请求索引必须大小写无关。
- Mac 与 Devbox 存在时钟偏差；捕获新鲜度允许 30 秒偏差，但仍校验请求过期和 `turnId`。
- 图片 Context 的 Base64 事件可超过普通音频帧；WebSocket 上限当前为 12 MiB。
- AppKit 使用左下原点，ScreenCaptureKit 使用左上原点，Region 必须转换 Y 轴。
- Electron 首次 AX 读取需要提前启用 Accessibility，并保存 Violet 获取焦点前的元素。

### 音频与启动

- Qwen Audio 是默认运行时；Pipeline 只能显式启用，禁止会话内静默切换。
- 内置扬声器播放期抑制麦克风；有线耳机需结合 `hdpn` 数据源识别并保留语音打断。
- 自然告别必须等待回复播放完成后再停止会话。
- 验收启动必须使用 LaunchServices；从 TRAE 沙箱直接启动可能触发 Keychain `100013`。

### 部署与安全

- Devbox 数据目录固定为 `/data00/violet`；运行秘密只在 `/dev/shm/violet`。
- 服务仅监听宿主机回环地址，Mac 通过 SSH 隧道访问。
- Devbox 只部署 Codebase/GitHub 已同步的确定提交；不要覆盖或清理远端原有脏仓库。
- Docker 单文件 bind mount 固定旧 inode；轮换运行秘密后必须重建或重启 Core。
- 历史授权不能用于新的部署、发布、删除、付费或权限扩张。
- 不读取保密工作内容，不记录音频、转写、截图或秘密到诊断日志。
- 真实麦克风、屏幕、锁屏、睡眠和前台交互测试只能在用户明确批准的窗口执行。
- 2026-09-07 经用户审核后移除整包导入的通用项目 Skills 及其未跟踪
  `skills-lock.json`；长期项目规则统一收敛到根目录 `AGENTS.md`，处理记录见
  [开发规则审计与处理记录](./development-rules-review.md)。
- 两个远端 `main` 提交哈希不同但文件树相同；不以“整理”为由强推或重写历史。
