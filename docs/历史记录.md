## 2. 项目目标

Violet 是只为用户本人服务、长期连续存在、跨设备保持同一身份的私人智能体。设备是身体，模型、Skill、MCP 和 Agent 是可替换能力；Violet 的身份、关系、记忆、判断和责任不属于任何单一组件。

第一阶段要形成完整闭环：

```text
自然交流
→ 理解已授权的当前处境
→ 正确记住共同经历
→ 自主选择回答或行动
→ 持续执行、验证和交付
```

长期不变的产品边界：

- “在场”表示可被唤醒，不表示持续监控；感知由用户主动开启。
- 第一阶段只服务用户本人，只做 Mac 身体，不读取保密工作内容。
- 设备端负责权限、范围、敏感过滤和数据出境控制，云端负责主要智能。
- 绝对秘密始终禁止上传、记忆或转发；受控敏感信息默认遮挡。
- 记忆统一连续，不以聊天会话列表切割 Violet；记忆准确性高于表面连续性。
- Violet 可以自主形成记忆，但记忆必须可见、可追溯、可编辑、可删除。
- 认知自由、行动受托；高风险或不可逆操作必须事前审批。
- Violet 对交付质量负责，用户拥有最终验收权。
- 最高使命是“为人民服务”。

## 5. 已锁定的工程决策

### 身份、对话与记忆

- 用户始终只面对一个 Violet。
- 事件账本记录发生过什么，认知模型记录当前相信什么；认知模型必须能由事件账本重建。
- 最终用户转写和最终回复可持久化；原始音频、临时转写、模型推理和无关截图不持久化。
- Context 是短时证据，不等同于长期记忆。
- 用户纠正必须更新当前认知，旧结论不得继续作为当前事实。

### 感知与隐私

- 感知证据优先级：用户明确框选 > 应用结构化数据 > Accessibility > OCR/视觉 > 推断。
- 任何截图在出境前必须完成本地 OCR、秘密阻断和敏感遮挡。
- Region 框选前清除旧 Context，创建新 UUID；框选时隐藏浮窗，完成后恢复。
- AppKit 使用左下原点，ScreenCaptureKit 截图区域使用左上原点，Region 必须转换 Y 轴。
- 保密应用只发送“本地策略阻止感知”，不发送内容。

### 实时语音

- Qwen-Audio 3.0 Realtime Plus 是默认运行时。
- `Paraformer → DeepSeek → CosyVoice` 是手动降级和供应商替换基线。
- Mac 只负责设备音频；身份、记忆、策略、审计和事件落账始终由 Core 负责。
- 唤醒默认关闭；开启表示允许本地持续 KWS，唤醒前 PCM 不上传、不写盘、不记录。
- 当前 sherpa 开放词汇模型召回不足，不能通过继续降低阈值换取误触发风险。

### 存储、部署与运维

- PostgreSQL 是身份、事件、任务和记忆的事实源；内容在应用层信封加密后写入。
- TOS 使用私有桶、最小权限、客户端信封加密、SSE-TOS、版本控制和生命周期。
- Devbox 服务只发布到宿主机回环地址，Mac 通过 SSH 隧道访问。
- 运行秘密只存在于 Mac 本地秘密源和 Devbox `/dev/shm`，不进入 Git、镜像、数据库、日志或备份。
- Devbox 固定数据目录为 `/data00/violet`；旧目录仅作为历史回滚点，不再作为当前部署目录。
- Devbox 用户必须保持 linger，避免登出时清理 `/dev/shm/violet`。
- 内部 Codebase 是集成远端，GitHub 是可迁移镜像；Devbox 只部署两端已同步的确定提交。

### 开发与交付

- 自动测试不得操作真实麦克风、扬声器、全局快捷键、锁屏、睡眠或用户前台应用。
- 真实系统权限、音频和前台交互测试只在用户明确批准的窗口执行。
- 开发 Agent 不能自行批准自己的交付。
- Core 不直接执行文件、终端、Git 或浏览器等不可信工具；这些能力属于后续隔离 Worker。
- 不因追求扩展性提前引入微服务、消息队列或独立向量数据库。

## 6. 已知限制与经验

- DeepSeek Vision 在真实截图上的长尾约 9–20 秒；本地步骤约 1.5–3.6 秒。当前通过后台预取改善体感，不再继续做供应商级延迟调优。
- Electron 首次读取选区需要提前启用 Accessibility 支持，并在 Violet 获得交互焦点前保存目标元素引用。
- 开发构建签名变化会使 macOS TCC 授权失效；需保持稳定 requirement，必要时删除旧授权并重新添加 App。
- macOS Voice Processing 在已测耳机路径会产生全零输入并压低系统音量，当前使用原始输入和本地能量门处理打断。
- Docker 单文件 bind mount 固定旧 inode；轮换 `/dev/shm` 密钥后必须重建或重启 Core。
- Violet 显示 offline 时应先检查 Kerberos 票据；票据过期会使 SSH 隧道立即退出。
- 部署时必须先核对数据目录和事件数量。曾因历史目录与默认目录不一致启动空库，现已统一到 `/data00/violet`。
- 备份当前使用同一恢复密钥；1D 的彻底删除需要补齐备份代轮换和恢复前删除墓碑重放。
