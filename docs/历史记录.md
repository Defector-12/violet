## 关键工程教训

- 视觉截图、冻结坐标和 `turnId` 必须来自同一轮；旧图和晚到结果不能复用。
- Swift UUID 与 Core 索引需大小写无关；跨设备时间只允许有限偏差。
- 图片 Base64 事件比音频帧大，鉴权 Realtime WebSocket 上限为 `12 MiB`。
- AppKit 与 ScreenCaptureKit 坐标原点不同，Y 轴只能转换一次。
- 模型自报 confidence、颜色和框包含关系不能证明语义正确。
- object → label/value 问答不能要求答案文字框包含用户指向的对象。
- 普通指针裁图会丢失布局关系；当前只读问答使用完整单屏和冻结坐标。
- live cursor 会在异步截图期间移动并与冻结坐标冲突；最终截图不画 cursor。
- OCR 只负责本机绝对秘密阻断和受控敏感遮挡，不作为模型答案证据。
- Qwen 是视觉意图路由器；Core 不维护第二套自然语言关键词规则。
- 供应商支持插话时，以服务端 `speech.started` 为准；本地连续 4 帧能量门只作兜底。
- 测试记录器必须显式、限时、失败关闭；报告不能替代原始证据。

## 当前边界

- `Look` 默认关闭，非视觉问题不截图。
- 不持续采帧，不读取剪贴板，不增加 Trae 专用适配器。
- 保密应用、绝对秘密、本机遮挡、轮次、取消、过期和生命周期门禁保持确定性。
- 严格点框属于未来执行动作，不属于当前只读问答。
- 运行秘密只在既定 secret 文件中使用，不进入源码、命令参数、日志或 Git。
- Release 1D 及后续工作不因 1C 收尾自动获得开发或部署授权。
