无需为后续验收重复构建。

## 原五步故事（保留为历史操作说明）

1. 点击“记忆”入口，打开“Violet · 记忆”窗口。初始“自动学习记忆”应关闭、列表为空。通过窗口打开开关，
   等待保存结束；在终端输入 `snapshot`，保存服务端设置。
2. 在文字对话发送：**“我平时喜欢用紫色书签。”** 不添加“记住”。保持记忆窗口打开，
   等待本轮回答完成和“有新变化，刷新查看”提示。记录提示是否在一分钟内出现；
   点击提示，确认新增紫色书签偏好，标记为自动来源，详情原话来自本轮。终端输入
   `snapshot`，再输入实际观察，例如“第二步：出现提示，来源原话一致”。
3. 终端输入 `restart`。它重启隔离 Mac 和 Core，保留数据库，再次确认两端 recorder ready。
   打开记忆窗口，确认开关仍开启，紫色书签记忆与来源仍在。输入 `snapshot`。
4. 在窗口关闭自动学习。发送：**“我平时喜欢用橙色笔记本。”** 等回答完成，终端输入
   `snapshot`；应无橙色笔记本自动记忆或待处理任务，原有紫色书签记忆仍可查看。
5. 通过窗口重新开启，不重新发送第四步内容。输入 `restart`，核实开关开启且没有补入
   橙色笔记本。再发送 **“我平时喜欢用蓝色文件夹。”**，等待更新提示并查看自动来源。
   输入 `snapshot`，记录实际观察，最后输入 `finish`。

出现失败就记录具体步骤与现象，不为补留证重做。终端其他文字会作为人工观察写入；
`snapshot` 保存当时真实设置、记忆及任务状态。脚本收集结束不等于验收通过，助手需
对照 Mac/Core 原始请求、实际回答、来源、任务状态和人工观察作出结论。
失败时先输入现象，再输入 `abort`，让脚本按失败结果收集证据并清理临时环境；
成功完成五步后输入 `finish`。
