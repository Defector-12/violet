# Release 1B 实时语音验收

> 状态：已完成。Qwen 是默认运行时；Pipeline 是显式手动降级与供应商替换基线。
> 本文只保留可重复验收方法、交付证据和回归条件。实现背景见
> [工程路线](./engineering-roadmap.md)。

## 1. 执行方式

验收记录默认关闭，只记录单调时间、事件类型、停止原因及随机生成的关联 ID。禁止记录
音频、转写、回复、设备令牌、供应商密钥、模型推理或用户文件内容。

```bash
klist -s || kinit
pnpm macos:app
./scripts/start-macos-acceptance.sh
pnpm acceptance:report -- .local-acceptance/<file>.ndjson
```

- 真实 Qwen 批量调用前确认累计费用不超过本轮已批准上限。
- App 必须先退出，再由 LaunchServices 验收脚本启动。
- 日志默认写入被 Git 忽略的 `.local-acceptance/`。
- 报告退出码：全部通过为 0，样本不足或门禁失败为 1，日志/schema 非法为 2。

## 2. 验收门槛

| 门禁 | 样本 | 通过标准 |
|---|---:|---|
| 浮层触发 | 100 | 触发到 `popoverDidShow` 的 p95 ≤ 200ms |
| 真实语音 | 30 | 服务端停止说话到首个本地音频排队的 p95 ≤ 2s |
| 回复打断 | 30 | 检测到打断到停播的 p95 ≤ 300ms |
| 麦克风停止 | 50 | 停止请求到采集关闭的 p95 ≤ 1s |
| 已取消回复 | 全部 | 停播后旧 response 再次排队次数为 0 |
| 正常会话 | 全部 | 非预期失败次数为 0 |

样本应覆盖中英文、混合语言、长停顿、背景噪声、语音/点击打断、耳机/扬声器，以及
收起浮层、主动停止、锁屏、睡眠、超时和断线。自动化测试不得占用真实麦克风、播放
声音、锁屏或睡眠；真实设备步骤只在用户明确批准时执行。

- SSH 断线、250ms 单向延迟、外置耳机、Bluetooth 和 MacBook 内置路由完成真实恢复
  验证。
- 锁屏、显示器睡眠和 46 秒 Deep Idle 恢复已通过；重复锁屏和整机睡眠只保留发布前
  用户在场抽样。

### Pipeline 替换基线

2026-08-24，提交 `3e0e2ab`：

- `Paraformer → DeepSeek → CosyVoice` 三次静默 canary 均准确转写中文测试句。
- Paraformer 断句到首音频为 `1.94s / 1.92s / 1.34s`。
- 取消后 1 秒内迟到音频为 0，且没有取消后的完成事件。
- 该结果只证明 Pipeline 可作为显式替换基线，不改变 Qwen 的默认地位。

### 账本与隐私

- 最终用户转写和助手回复可恢复为 `user`、`assistant` 事件。
- 内容使用 AES-256-GCM 信封加密；账本不保存原始音频、临时转写或推理。
- 静默 canary 的 PCM 只存在于内存；临时数据库在验证后删除。

## 4. 回归条件

以下变化必须重新执行相应门禁：

- 更换默认 Realtime 供应商、模型、VAD、音频格式或音色。
- 修改播放队列、打断、麦克风停止、SSH 重连或会话生命周期。
- 修改验收日志 schema 或汇总器。

故障回归至少覆盖：监听/处理/播放时断网、正常/异常 WebSocket 关闭、迟到事件、音频
路由切换和隧道恢复。不得因测试方便启用会话内静默供应商切换。
