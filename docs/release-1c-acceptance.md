# Release 1C / 1C.1 验收

状态：功能、用户产品验收、工程收尾、Git 交付与最终部署均已完成。
本文件是当前状态与剩余工作的事实源；不能把历史测试数字当成当前版本的新测试。

## 交付范围

- 原生 Mac 的唤醒、手动选中文字/窗口/区域、按需视觉问答与连续对话。
- Natural Pointing：Qwen 调用 `inspect_current_view` 后，Mac 截取冻结鼠标所在的
  完整单屏，经本机隐私过滤后，将一张图、冻结坐标和原问题交给 DeepSeek。
- DeepSeek 返回 `answer` 和 `confidence`；Core 保留授权、当前轮次、请求关联、
  过期、取消、生命周期及 `confidence >= 0.7` 门禁。
- 已删除局部裁图、AX 正文捷径、OCR 答案证据、target schema、颜色/位置二次否决和
  Core 关键词路由。手动 Selected Text 保持独立。
- 截图不包含 live cursor，避免异步采集期间鼠标移动后与冻结坐标形成两个目标。
- 关闭 Look 或非视觉问题不截图；保密应用与绝对秘密阻断，受控敏感信息本机遮挡。
- 图片、OCR 和临时 Context 不进入长期记忆；实时对话中先前的工具答案不是当前画面证据。

长期记忆、持久任务、执行动作、Worker 和浏览器增强不属于本次交付。
