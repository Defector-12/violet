## 2. 当前候选

- `Look` 默认关闭；普通问题不截图。
- Qwen 判断需要视觉后，Core 才按当前 `turnId` 请求 Mac 采集。
- Mac 在 `input.speech.stopped` 到达时按 `turnId` 固定前台目标、AX 焦点和鼠标坐标。
  后续视觉请求必须在 30 秒内消费同一轮锚点；AX 失败后才截取鼠标所在的单个显示器。
- 图片出境前执行本地 OCR、绝对秘密阻断和受控敏感遮挡；OCR 原文不作为目标证据，
  OCR 识别置信度也不限制截图本身的证据置信度。
- 图片在 `8 MiB` 内保持原始像素尺寸；超限时先降低 JPEG 质量，仍超限才等比缩小。
- 本地 DeepSeek 候选在一次请求中接收未改动的全屏图和一张局部证据图。选区问题若
  检测到“鼠标附近、宽扁、连通的默认蓝色高亮”，局部图紧贴该高亮并留 16 像素；
  目标框使用该像素区域。检测不到时回退到最多 `1200 x 320` 的鼠标局部图和模型框。
  蓝色只是与问题、鼠标和模型文字共同使用的证据，不单独决定答案。
- 裁图由冻结鼠标和像素连通区域确定，不依赖模型先猜框，也没有第二次模型调用。
  Core 对模型坐标只容许一个原图像素的量化误差。
- Mac 候选不再把定位环画到证据图上，避免覆盖字符和隐私遮挡；坐标仍随图传递。
- 模型参数为 `detail: high`、`temperature: 0` 和问答 JSON 输出。它们不能保证正确率
  或完全确定性，必须对固定输入统计全部回放结果。
- Core 校验请求关联、新鲜度、置信度、位置、颜色和目标语义；图片缺少鼠标点、目标框
  未包含该点、定位环被当作目标，或选区缺少完整文字时拒绝回答。
- 校验失败时明确返回不可可靠定位，不使用旧 Context 或模型猜测兜底。
- 新语音轮次取消旧视觉任务；截图不进入长期账本或记忆。
- 按需采集先读 AX 选中文字，再读冻结鼠标下的静态文字；两者均不可用才截图。
  AX 指针读取不再要求存在焦点元素。每次新的采集请求重新读取，不复用跨轮截图。
- 已返回的文字证据或视觉答案会作为工具结果留在实时对话上下文中，普通追问可能直接
  基于这些结果回答。显式视觉词触发 Core 门禁，其余依赖模型调用工具；不能以回答正确
  或速度快证明该轮重新采集了当前画面。

当前未实现且不属于本方案：拖拽监听、剪贴板读取、Trae 专用适配器、持续采帧和产品
默认图片缓存。显式诊断录制是独立、一次性的例外，见第 6 节。

已确认的稳定性修复：

- Swift 大写 UUID 与 Core 小写请求索引改为大小写无关匹配。
- Mac 与 Devbox 约 49ms 时钟偏差不再误拒新证据；允许 30 秒跨设备偏差，仍校验请求
  过期和 `turnId`。
- 真实图片 Context 约 450–540 KB，原 150 KB WebSocket 上限会触发 close code 1009。
  当前上限为 12 MiB，并由“大图片事件后同一连接继续回答”的集成测试保护。
- 后台生命周期审计发现，锁屏或睡眠结束 Realtime 会话时，通用会话结束回调可能重新
  启动 KWS；机器唤醒但仍处于锁屏界面时也可能过早恢复。当前本地候选分别持有系统
  睡眠、屏幕休眠和用户会话失活门禁，并在系统暂停或 App 退出时取消待启动的唤醒回执。
- 本地 OCR 可能把同一行卡号拆成多个 observation，旧过滤器逐块检查时会漏掉。当前
  候选先按视觉行聚合再检测，命中后遮挡该行全部组成区域，OCR 摘要也不保留原值。

### Natural Pointing

1. `Look` 关闭时 20 次唤醒产生的屏幕或 AX Context 为 0。
2. `Look` 开启但问题不依赖视觉时，20 次均不截图、不上传。
3. AX 可读时不截图；AX 不可读时才进入截图链路。
4. 连续变化的窗口或鼠标问题只能使用当前 `turnId` 证据。
5. 鼠标指向、`33` 徽标和绿色发送按钮必须正确识别。
6. 低置信度、无目标框、位置或颜色冲突时必须明确失败。
7. 选中文字、鼠标附近文字、文章、图片和图表各 10 次，正确率至少 90%，跨轮误命中为
   0。

## 6. 数据边界

- Context 默认 5 分钟过期；关闭浮层、锁屏、睡眠、撤权或会话结束时清理。
- 临时图片使用独立 DEK 加密后写入 `violet/tmp/context/`，会话结束主动删除全部版本和
  delete marker；TOS 生命周期 24 小时兜底。
- Context 不进入长期记忆，也不改写现有对话账本。
- 普通验收日志只记录时序、类型、长度、状态和随机 ID，不记录内容。
- 显式 `--record-pointing` 验收模式在启动后的 15 分钟内仅保存下一次按需图片输入，
  无论该轮最终成功或失败。复用已经隐私过滤的图，包含问题、鼠标、轮次与图片 hash，
  不包含 OCR 原文、音频或凭证；默认关闭，不增加任何截图请求。
- 样本目录 `0700`、文件 `0600`，不覆盖既有证据，Git/Docker 忽略。新样本有效期
  24 小时，App 运行时定时删除，重用该录制目录时清理过期文件；若 App 已退出，
  开发者需执行 `--purge-expired`。回放工具拒绝已过期样本。
- 2026-09-08 终端选区与绿色按钮诊断关闭后，旧版 A/B 样本、截图、回放结果和调试
  日志已从本机删除；Devbox 发布目录未包含 `.local-acceptance` 或 `.dbg` 副本。

## 7. 回滚

- 关闭 `Look`：停止自动按需感知，保留手动 Context 和普通语音。
- `VIOLET_VISION_PROVIDER=deterministic`：停止真实视觉模型调用。
- `VIOLET_CONTEXT_STORAGE_PROVIDER=memory`：停止 TOS 临时对象写入。
- 删除 Context Session：Release 1B 文字与实时语音路径保持不变。
- Vision 超时、路由失败或证据校验失败：明确失败，不使用旧 Context 替代。
